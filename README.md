# AI Refactoring Agent

An educational project for exploring AI usage in software development.

This project experiments with using local AI models for iterative code refactoring. 
It is primarily generated by AI and designed for learning purposes only. Created as a classroom project.

## Requirements

- [Ollama](https://ollama.com) with a local model (e.g., qwen2.5-coder:7b)

## Usage

```bash
# Analyze code and show refactoring suggestions
python src/refactoring_agent.py <file> --json

# Apply suggestions interactively
python src/refactoring_agent.py <file>

# Apply all suggestions automatically
python src/refactoring_agent.py <file> --auto-apply

# Write output to a different file
python src/refactoring_agent.py <file> --auto-apply -o <output_file>

# Use a specific model
python src/refactoring_agent.py <file> --model qwen3-coder:30b
```

**Not recommended for production use.**
